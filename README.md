# 🛡️ Automação de Resposta a Incidentes com Wazuh

Este repositório documenta a implementação de **respostas automatizadas a incidentes de segurança** utilizando o Wazuh em ambiente de laboratório.

O foco está em detectar atividades maliciosas e aplicar ações automáticas de contenção, simulando um cenário real de SOC (Security Operations Center).

---

## 🎯 Objetivo

- Implementar Active Response no Wazuh
- Automatizar respostas a incidentes de segurança
- Reduzir tempo de resposta (MTTR)
- Simular cenários reais de ataque

---

## 🧰 Ambiente

- Wazuh Manager (Linux)
- Agente Windows
- Sysmon
- Active Response
